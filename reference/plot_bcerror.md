# Plot base-calling error in a heatmap.

Plot base-calling error in a heatmap.

## Usage

``` r
plot_bcerror(tbl, data, title_suffix, include_legend = TRUE)
```

## Arguments

- tbl:

  tibble of bc-delta values

- data:

  sequence to structure file

- title_suffix:

  string

- include_legend:

  Logical, include legend in the plot.
