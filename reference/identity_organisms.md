# List supported organisms for identity elements

Returns the names of organisms for which tRNA aminoacylation identity
element data is available.

## Usage

``` r
identity_organisms()
```

## Value

A character vector of organism names.

## Examples

``` r
identity_organisms()
#> [1] "Escherichia coli"         "Saccharomyces cerevisiae"
#> [3] "Homo sapiens"            
```
