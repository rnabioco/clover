# Amino acid color palette.

Return a named character vector of colors for the 20 standard amino
acids plus fMet, Ile2, and SeC.

## Usage

``` r
aa_colors()
```

## Value

A named character vector of hex colors.

## Examples

``` r
aa_colors()
#>       Ala       Arg       Asn       Asp       Cys       Gln       Glu       Gly 
#> "#1f77b4" "#ff7f0e" "#2ca02c" "#d62728" "#9467bd" "#8c564b" "#e377c2" "#7f7f7f" 
#>       His       Ile       Leu       Lys       Met       Phe       Pro       Ser 
#> "#bcbd22" "#17becf" "#aec7e8" "#ffbb78" "#98df8a" "#ff9896" "#c5b0d5" "#c49c94" 
#>       Thr       Trp       Tyr       Val      fMet      Ile2       SeC 
#> "#f7b6d2" "#c7c7c7" "#dbdb8d" "#9edae5" "#393b79" "#5254a3" "#6b6ecf" 
```
