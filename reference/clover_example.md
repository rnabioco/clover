# Provide working directory for clover example files.

Provide working directory for clover example files.

## Usage

``` r
clover_example(path)
```

## Arguments

- path:

  path to file

## Value

A string with the path to the example file.

## Examples

``` r
clover_example("ecoli/config.yaml")
#> [1] "/home/runner/work/_temp/Library/clover/extdata/ecoli/config.yaml"
```
